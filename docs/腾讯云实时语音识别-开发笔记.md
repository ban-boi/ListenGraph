# 腾讯云实时语音识别（WebSocket）开发笔记

> 官方文档：https://cloud.tencent.com/document/product/1093/48982
> 计费文档：https://cloud.tencent.com/document/product/1093/35686

---

## 1. 概述

实时语音识别通过 WebSocket 协议，客户端边发送音频分片，边接收识别结果。整个流程分两个阶段：

1. **握手阶段**：建立 WebSocket 连接，URL 中携带签名参数
2. **识别阶段**：通过 WebSocket 发送音频二进制帧，接收 JSON 文本结果

---

## 2. WebSocket 连接地址

```
wss://asr.cloud.tencent.com/asr/v2/<appid>
```

连接时将参数拼在 URL query string 中。

---

## 3. 连接参数（握手阶段）

### 必填参数

| 参数 | 类型 | 说明 |
|---|---|---|
| `secretid` | String | 腾讯云 API 密钥的 SecretId |
| `timestamp` | Integer | 当前 UNIX 时间戳（秒），与当前时间相差过大会导致签名过期 |
| `expired` | Integer | 签名过期时间戳（秒），必须 > timestamp，差值 < 90 天 |
| `nonce` | Integer | 随机正整数，最长 10 位 |
| `engine_model_type` | String | 引擎模型类型（见下方引擎列表） |
| `voice_id` | String | 音频流唯一标识，推荐 UUID，最长 128 位。**每次连接必须重新生成**，连接中断后作废 |
| `signature` | String | 接口签名参数 |

### 可选参数

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `voice_format` | Int | 4 | 音频编码：1=pcm, 4=speex, 6=silk, 8=mp3, 10=opus, 12=wav, 14=m4a, 16=aac |
| `needvad` | Int | 0 | 是否开启人声检测切分：0=关闭, 1=开启。**超过 60 秒音频建议开启** |
| `filter_dirty` | Int | 0 | 过滤脏词：0=不过滤, 1=过滤, 2=替换为* |
| `filter_modal` | Int | 0 | 过滤语气词：0=不过滤, 1=部分, 2=严格 |
| `filter_punc` | Int | 0 | 过滤句末句号：0=不过滤, 1=过滤 |
| `filter_empty_result` | Int | 1 | 是否回调空结果：0=回调, 1=不回调。**需要 0/2 配对时设为 0** |
| `convert_num_mode` | Int | 1 | 数字转换：0=不转换, 1=智能转阿拉伯数字, 3=数学模式 |
| `word_info` | Int | 0 | 词级时间戳：0=不显示, 1=显示(无标点), 2=显示(含标点), 100=字词级(仅16k_zh_en) |
| `hotword_id` | String | - | 热词表 ID（需先在控制台创建） |
| `hotword_list` | String | - | 临时热词表，格式：`"热词|权重,热词|权重"`，最多 128 个，权重 1-11 或 100 |
| `customization_id` | String | - | 自学习模型 ID |
| `vad_silence_time` | Int | 1000 | 静音断句阈值（ms），范围 500-2000，需配合 needvad=1 |
| `max_speak_time` | Int | 60000 | 强制断句（ms），范围 5000-90000，连续说话时强制返回 slice_type=2 |
| `noise_threshold` | Float | 0 | 噪音阈值，范围 [-2,2]，慎用 |
| `input_sample_rate` | Int | - | 仅支持 8000，用于 8k PCM 音频在 16k 引擎下升采样 |
| `emotion_recognition` | Int | 0 | 情绪识别（增值付费）：0=关闭, 1=开启不显示标签, 2=开启并显示标签 |
| `replace_text_id` | String | - | 替换词汇表 ID，强制替换识别结果 |

## 5. 识别阶段

### 发送音频

- 建立 WebSocket 连接后，发送**二进制帧**（Binary Frame）
- 音频分片建议每 **40ms** 发送一次
- 音频采样率需与引擎匹配（16k 引擎 → 16kHz 音频）
- m4a 格式的每个分片必须是完整的 m4a 帧

### 结束识别

发送结束标记，连接关闭后返回最终结果。

---

## 6. 返回结果格式

每条返回为 JSON：

```json
{
  "code": 0,
  "message": "success",
  "voice_id": "TBgVFCsxdn3i2DGt",
  "message_id": "TBgVFCsxdn3i2DGt_1",
  "result": {
    "slice_type": 2,
    "voice_text_str": "今天天气不错。",
    "start_time": 0,
    "end_time": 1200,
    "word_size": 8
  }
}
```

### 关键字段

| 字段 | 说明 |
|---|---|
| `code` | 0=成功，非0查看 message |
| `result.slice_type` | **核心字段**，见下方说明 |
| `result.voice_text_str` | 识别文本 |
| `result.start_time` | 本段起始时间（ms） |
| `result.end_time` | 本段结束时间（ms） |
| `result.word_size` | 词数 |

### slice_type 详解

| 值 | 含义 | 稳定性 |
|---|---|---|
| 0 | 一段话开始识别 | 可能返回空文本 |
| 1 | 识别中，**非稳态**结果 | 会变化，不要落库 |
| 2 | 识别结束，**稳态**结果 | ✅ 不再变化，可以落库 |

### slice_type 返回序列

根据音频情况，可能的序列：
- `0 → 1 → 2`（最常见：开始 → 中间多次更新 → 结束）
- `0 → 2`（短句：开始 → 直接结束）
- `2`（直接返回完整结果）

**开发要点：只处理 `slice_type=2` 做最终文本拼接，`slice_type=1` 可用于实时显示打字机效果。**

## 7. 热词功能

### 方式一：热词表（hotword_id）
1. 在腾讯云控制台创建热词表，获取 hotword_id
2. 每次连接传入 hotword_id

### 方式二：临时热词表（hotword_list）
- 格式：`"热词|权重,热词|权重"`
- 示例：`"腾讯云|10,语音识别|5,ASR|11"`
- 单个热词 ≤ 30 字符（≤ 10 个汉字）
- 最多 128 个热词
- 权重范围 1-11 或 100

### 权重说明
- `1-10`：普通热词，权重越高优先级越高
- `11`：**超级热词**，仅用于重要且必须生效的词，过多会影响整体字准率
- `100`：**同音同调替换**（仅 8k_zh/16k_zh），如"蜜制|100"会把"秘制"强制替换为"蜜制"

> ⚠️ hotword_id 和 hotword_list 同时传入时，**只有 hotword_list 生效**

## 9. 开发注意事项

1. **voice_id 必须每次重新生成**（UUID），断连后旧的作废
2. **音频采样率与引擎匹配**：16k 引擎用 16kHz 音频，8k 引擎用 8kHz
3. **音频分片频率**：建议 40ms 一次，不要攒太大包
4. **超过 60 秒必须开 VAD**（needvad=1），否则会强制断句影响效果
5. **签名有效期**：expired - timestamp < 90 天
6. **slice_type=1 是中间结果**，不要用它做最终存储
7. **filter_empty_result=0** 如果需要 slice_type 0 和 2 配对（如外呼场景判断是否有人声）
8. **并发限制**：默认单账号限制，可通过购买叠加包提升
9. **m4a 格式**：每个分片必须是完整的 m4a 帧，不能随意切割
