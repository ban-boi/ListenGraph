# Auto Fit 最小可读字号设计

**日期**：2026-05-15
**状态**：待审阅
**影响文件**：`apps/extension/src/sidepanel/App.tsx`、`GraphNodeCard.tsx`、`SettingsPanel.tsx`、`types.ts`

---

## 问题

当前 sidepanel 首次有节点时会自动执行一次 `fitView({ padding: 0.16 })`，后续更新不再自动缩放。这避免了画面跳动，但首帧如果图谱范围较大，React Flow 会把 zoom 压得很低，导致节点正文视觉字号明显小于可读范围。

继续微调 `fitView` padding 或全局 `minZoom` 只能间接缓解问题：

- padding 影响“图离边缘多远”，不能表达“文字至少多大”。
- `minZoom` 会限制用户手动缩小，违背用户自由浏览大图的需求。
- 后续语义布局如果更横向、更结构化，图谱 bounds 会继续变大，单纯调系数会反复失效。

## 产品契约

自动适配视图时，系统应尽量展示完整图谱，但不能把节点正文缩到用户设定的最小可读字号以下。

用户手动缩放不受这个限制。也就是说：

- 自动 `fitView` / 重置视图：受最小可读字号约束。
- 鼠标滚轮、触控板、React Flow 控件手动缩放：仍允许缩小到现有 `minZoom`。

## 推荐方案

引入“自动适配最小字号”设置，默认 `12px`。节点正文当前基准字号为 `12px`，自动适配时根据设置计算 zoom 下限：

```text
minReadableZoom = readableFontPx / baseNodeBodyFontPx
```

示例：

- 设置 `12px`：自动适配 zoom 不低于 `1.0`
- 设置 `10px`：自动适配 zoom 不低于 `0.83`
- 设置 `14px`：自动适配 zoom 不低于 `1.17`

如果完整图谱需要更小的 zoom 才能全部塞入视口，系统应停在可读 zoom 下限，让部分图谱需要平移查看，而不是牺牲字体可读性。

## 行为细节

### 首次自动适配

首次有节点时仍触发自动适配，但不直接调用裸 `fitView`。流程改为：

1. 用 React Flow 计算或应用 fit bounds 的目标 viewport。
2. 计算 `targetZoom`。
3. 将最终 zoom 夹到 `Math.max(targetZoom, minReadableZoom)`。
4. 应用 viewport，并保持当前 padding 语义。
5. 标记 `hasAutoFitRef.current = true`。

### 手动重置视图

新增“重置视图”或“适配视图”入口时，也复用同一套可读性约束。这样用户在图谱增长后可以主动恢复概览，但恢复后的文字仍可读。

### 用户手动缩放

React Flow 的 `minZoom` 保持现状，不因最小可读字号而上调。用户明确手动缩小视图时，系统认为用户在用“概览/定位”模式，不强行纠正。

## 设置 UI

在现有设置面板中增加一个“图谱显示”小节：

- 字段：`自动适配最小字号`
- 默认：`12px`
- 建议选项：`10px`、`12px`、`14px`、`16px`
- 说明文案：`只影响自动适配和重置视图；手动缩放不受限制。`

设置持久化可以复用当前通用 `settings` store，使用独立 key，例如 `graph-display-settings`。不要塞进 provider config，避免把显示偏好和 ASR/Structurer 配置混在一起。

## 与后续语义布局的关系

后续如果把语义结构更真实地表现为“观点右侧分出多个小点”，图谱会更横向，自动 fit 更容易为了完整展示而缩小。这个方案正好把边界说清楚：

- 可读性是自动视图的硬约束。
- 图谱过大时，自动视图宁愿不完整展示，也不把字缩到看不清。
- 节点 padding、节点宽度、连线长度、真实 DOM 尺寸测量属于第二阶段布局密度优化，不是这次字体问题的前置条件。

## 不做

- 不限制用户手动 zoom。
- 不把全局 `minZoom` 提高到可读阈值。
- 不在本次重写语义布局或引入 dagre/elk。
- 不把字号设置设计成节点内容排版系统；先只解决自动适配可读性。

## 测试用例

1. 小图谱：自动适配后能完整展示，zoom 不需要被可读下限抬高。
2. 大图谱：自动适配目标 zoom 低于可读下限时，最终 zoom 被抬到下限，部分图谱可通过平移查看。
3. 设置 `10px / 12px / 14px`：自动适配 zoom 下限随设置变化。
4. 用户手动滚轮缩小：仍可缩到 React Flow `minZoom`，不被最小可读字号拦截。
5. 重置视图按钮：行为与首次自动适配一致，受可读字号约束。
6. 设置保存并重开 sidepanel：显示偏好仍生效。
